# 商品标签视觉设计器

把「标签文案」变成「可评审、可计算、可交给印厂的版式规格与样张」；也能把**已有的真实标签**反算成可校验输入。

**四条纪律：**

1. **版式与合规分开判。** 只管「放在哪、多大、什么颜色、能不能印」；文案写什么、能不能写走 `label-taxonomy-governor`。**版式通过 ≠ 文案合规**。
2. **脚本只算几何与数值，不判合规。** 不能判断一句话是否违法、商标图样是否与注册证一致、配色是否符合品牌。
3. **审查既有稿不目测、不虚构参数。** 坐标要由源脚本或图像量测复算；量不准标 `需人工复核`，不从缩略图估值。
4. **没跑脚本就不许说跑过。** 报告首行写 `【执行声明】脚本：已运行（N 项）｜未运行（人工逐条）`。

## 触发条件

- 要给产品／包装标签排版、出样张、定视觉规格
- 要判断最小字号、视距可读性、底色与字色对比度
- 要核商标位置／面积、二维码静区、出血与安全边距
- **要审查已有的一批标签图／源脚本**，或拿一张真实标签做改版
- 要产出设计令牌供前端或印前复用
- 用户要求「不能动任何原文件」的只读审查

## 输入

| 输入 | 必填 | 说明 |
|---|---|---|
| 成品尺寸 W×H（mm） | ✅ | 从图像实测像素 + dpi 换算，不从文件名猜 |
| 区块清单 | ✅ | `id` / `type` / `x,y,w,h` / `font_mm` / `fg` / `bg` / `text` |
| 视距（mm） | ⭕ | 默认 400，采用默认值须在报告标注 |
| 印厂规范 | ⭕ | 有则覆盖 `config/visual-rules.json` 默认值 |
| `copy_references` | ⭕ | 文案声明引用的版面元素（如 `qrcode`、`emergency-phone`） |
| `wrapped_lines` | ⭕ | 真实排版脚本实测的断行结果，用于中文禁则复验 |
| `placeholder: true` | ⭕ | 声明该区块只是占位，不是已具备的功能 |
| 文案合规结论 | ⭕ | 已跑过 B 域合规则交叉引用；没有就注明「文案合规未核」 |

> 样张示例一律用**占位文案**。真实改版稿可用真实文案，但仍是设计稿不是印稿。

## 输出

1. `visual-spec.md` — 视觉规格表（按模板）
2. `visual-report.md` + `visual-report.json` — 版式校验报告（三态）
3. `label-proof.svg` / `.html` — SVG 样张与预览（可开标注层）
4. `tokens.css` / `tokens.json` — 设计令牌
5. `layout.json` + `design_input.json` — 真实改版时的实测布局与回灌输入
6. `零改动复核.txt` — 只读审查时的哈希前后比对
7. 待拍板项（配色、字体、品牌取舍、二维码真码、印厂规范）

## 规则包

| 文件 | 用途 |
|---|---|
| `references/visual-spec-rules.md` | 五层信息层级、栅格、字号、对比度公式、商标/码/印刷规则、评审五问、**v1.2 第十节实测规则** |
| `references/visual-reverse-engineering.md` | **v1.2 新增**：px→mm 反算、四份输入策略、实测布局回灌闭环、三类踩坑、零改动纪律 |
| `config/visual-rules.json` | 可配置阈值：字号、对比度、面积比、静区、TAC、**中文禁则字符** |
| `templates/visual-spec-template.md` | 视觉规格表模板 |
| `templates/redesign-spec-template.md` | **v1.2 新增**：真实内容改版规格表模板 |
| `examples/label-proof-input.json` | 可运行示例（占位文案） |
| `scripts/snapshot_unchanged.py` | **v1.2 新增**：零改动哈希基线／复核 |

## 自检

用户说「跑自检／测试一下」时，运行 `scripts/self_check.py` 并原样贴出输出（**22 条冒烟断言**）。

## 处理步骤

1. **分流**：从零设计 → 走第 3 步；审查已有标签 → 先走 `visual-reverse-engineering.md` 反算成 `regions[]`；真实改版 → 走第 5 步闭环。
2. **零改动基线**（用户要求不改动原文件时默认开启）：
   ```bash
   python scripts/snapshot_unchanged.py --root <原目录> --out baseline.txt
   # 交付前
   python scripts/snapshot_unchanged.py --root <原目录> --compare baseline.txt --out 零改动复核.txt
   ```
   运行时设 `PYTHONDONTWRITEBYTECODE=1`，产物只写新建独立子目录。
3. **确认尺寸与区块**。缺尺寸或坐标就列出来要，不猜；阈值边界**向上取整**后复验。
4. **版式校验与样张**：
   ```bash
   python scripts/check_visual_spec.py \
       --input examples/label-proof-input.json --config config/visual-rules.json \
       --output-md visual-report.md --output-json visual-report.json

   python scripts/render_label_proof.py \
       --input examples/label-proof-input.json --output label-proof.svg \
       --tokens-css tokens.css --tokens-json tokens.json --output-html label-proof.html --annotate
   ```
   在技能根目录执行；示例为包内真实文件，照抄即可运行。
5. **真实改版闭环**：视觉规格表 → 设计脚本重绘并输出 `layout.json`（含 `box_bottom_px`、行数、`wrapped_lines`）→ 生成 `design_input.json` → 跑校验 → 发现缺陷**真修**再复验，不改文档凑数。
6. **逐项三态结论**：`通过` / `不通过` / `需人工复核`，复核项写明不确定在哪。
7. **设计评审五问**（规则文档第七节）；未过的退回规格表改。
8. **交叉引用合规结论**：未核 → 明确写「本次仅做版式，文案合规未核」。
9. **单列待拍板项**：配色、字体、品牌表现、二维码真码、是否推广到其余款式。

## 脚本边界（务必如实转述）

| 事项 | 能做 | 不能做 |
|---|---|---|
| 对比度 | WCAG 2.1 公式算比值 | 配色是否好看／符合品牌 |
| 字号 | 类型下限 + 视距下限 | 字体选择、真实字形测量 |
| 几何 | 安全边距越界、四角判定、面积比 | 视觉平衡 |
| 二维码 | 边长、静区、越界 | 扫码验证内容 |
| 文案—版面一致性 | ✅ 声明的引用是否有对应区块 | 判断整句文案是否合规 |
| 中文断行禁则 | ✅ 基于实测 `wrapped_lines` 判行首／行尾标点 | 自动排版（等宽估算不替代字体测量） |
| 占位声明 | ✅ 标 `需人工复核` | 判断真码何时提供 |
| 印刷 | TAC、线宽、K 值、dpi 数值 | 实际印刷效果 |
| 法规 | ❌ | 由用户／法务复核 |

`config/visual-rules.json` 缺失或格式错误时脚本**报错退出，不静默回退**。

## 判定与归属

- **数值部分**由脚本决定，模型不得凭印象下结论。
- **定性部分**由模型判断并写出依据句。
- **拍板**由用户决定。用户坚持保留一条 `不通过` 的版式时，如实记录「此条在已知风险下保留」，不重复劝阻。

## 注意事项

- 样张是**设计稿不是印稿**，不得直接下厂；印刷参数采用默认值时写「需印厂确认」。
- **占位 ≠ 已具备**：二维码预留位、应急电话占位、空白喷码区不得当作功能已具备；不放可扫的假码、不编造号码。
- **规则来源域适用性**：商标四角规则来自卫生用农药标签项目，跨域先判适用性，未确认标 `需人工复核`。
- **版式通过 ≠ 文案合规**；法规类条款须复核现行有效版本。
- **不宣称首创**：承袭／增量见 `visual-spec-rules.md` 第零节与 `experience-provenance.md` 第七节。
- 不构成法律意见，不替代印厂工艺确认。
