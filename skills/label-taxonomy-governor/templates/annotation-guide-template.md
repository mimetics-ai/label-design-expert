### 不确定时的处理

- 标 `unknown`，记录对象 ID 与拿不准的原因
- 进复核队列，**不得**自行选一个「看起来最接近」的值

|---|---|---|---|---|---|---|
| | | | | | | `通过` / `不通过` / `需人工复核` |

> 一致率低于阈值时，优先修**定义句与边界例**，不要先怀疑标注人。
> 脚本不计算一致性系数；如需统计量（如 Cohen's kappa）由人工或外部工具完成，标 `需人工复核`。
